# v0.3.0 重量とヒンジ参考値

## 重量
重量はバー・重りを含む合計kgを任意入力する。未入力はnull、0kgは0として区別し、負数・非数・無限値は拒否する。セッション詳細と軽量履歴に保存し、後から変更できる。重量が旧記録にない場合は未入力として扱う。入力重量から適否・筋力・安全性を判定しない。

## ヒンジの参考値
体幹の往復候補ごとに、元の推定角度の観測範囲を表示する。股関節角度・体幹傾斜の90パーセンタイル−10パーセンタイルを変化幅とし、外れ値1点による極端な最大/最小の影響を抑える。
股関節は区間内の50%以上、体幹は80%以上で有効かつ4点以上のときだけ値を表示する。有効率は座標の取得率であり、角度精度の確率ではない。見えない関節の値は補間しない。姿勢推定の系統的なずれは残るため、「2D推定・部分データ」と表示する。変化幅からヒンジの正しさや良いフォームの点数は出さない。
元のレップ検出器、角度の可視性基準、解析モデル、解析版は変えない。過去の保存結果も元のrowsがあれば参考値を表示できる。

## 腰背部の推定を別機能にする理由と次の実装条件
現在のPoseが出力する肩・股関節・膝の点では、肩と股関節の間の胸椎・腰椎の局所形状や骨盤の向きを観測できない。体幹傾斜の同じ値で、丸まった姿勢・反った姿勢・中立の姿勢があり得るため、体幹傾斜を背骨の丸まりや腰の反りの数値へ変換しない。
重り・セーフティバーが映ることを通常の撮影条件として扱い、映像からの腰背部評価は次の別機能として検証する。

1. レップの上部・最大前傾点・上昇途中のフレームを取得し、腰背部が実際に見えるか判定する。
2. 背中の輪郭・胸郭・骨盤の関係を扱える画像モデルや追加のランドマーク方式を選定する。
3. 衣服、遮蔽、遠近、カメラ角度による判定保留条件を設ける。隠れた形状を確定扱いしない。
4. 本人の参照フォームとトレーナーの評価に対して検証し、丸まり傾向・反り傾向を確度と根拠フレーム付きで表示する。関節角度・確定本数とは別表示にする。
5. 外部画像モデルを使う場合は端末内処理と区別し、画像送信の同意・サーバー側認証・費用を設計する。キーを公開Webコードへ埋め込まない。

今回の更新では画像モデルを呼び出さず、「背中の丸まり・腰の反り：未評価」と表示する。長い注意文は折りたたみの計測詳細へまとめる。

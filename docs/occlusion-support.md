# 重り・セーフティバーによる部分遮蔽への対応

## 今回の修正
- 肩・股関節・膝・足首の全点が揃わないと全計測を無効にする方式を廃止。
- 股関節角度は肩・股関節・膝、膝角度は股関節・膝・足首、体幹傾斜は肩・股関節を個別に検証する。
- 足首が隠れても、股関節角度と体幹傾斜が計測できれば既存のヒンジ候補検出を継続する。
- レップ中の膝角度が一部欠けた場合、膝の最小角度は計測不可とし、比較対象から外す。欠測を0度と解釈しない。
- 計測項目別に有効フレームの割合を表示する。visibilityの基準0.65は緩めない。
- 解析版をrdl-2d-v3へ更新。既存の保存結果は変更せず、新旧版の比較には再解析が必要。

## 限界と次の検証
今回の変更は計測・検出ロジックの修正で、姿勢モデルそのものや骨格の推定座標は変えていない。物体の除去、隠れた関節の生成、左右の自動切替は行わない。
股関節・膝・肩が隠れて股関節角度を計測できない区間では、今までどおりレップ検出を保留する。体幹傾斜だけでは同じ基準のフォーム比較を成立させない。

実際に失敗した動画で、各関節のvisibility、計測有効率、手動のレップ区間を比較して残る原因を調べる。足首以外が遮られる場合は、撮影側の確認、反対側を固定選択した場合の計測率、Poseのモデル比較、体幹のみを使う低確度の候補検出を次の候補として検証する。低確度候補は完成レップや角度評価と区別する。
セーフティバーは撮影のために外さない。可能ならカメラの高さ・位置を少し調整して、股関節と膝が見える条件を比較する。

## 実機確認
1. 更新版で、重りが映った元の動画を再解析する。
2. 股関節・膝・体幹の計測率、レップ候補数、実際の本数を記録する。
3. 膝角度が計測不可でも、股関節・体幹の比較画面と保存・再読込が動くか確認する。
4. 0候補の場合は撮影側が左右で合っているか確認し、動画でどの関節が隠れているか調べる。
実動画と物理iPhoneの改善率は未検証。合成Poseのテストだけで遮蔽時の認識精度を断定しない。

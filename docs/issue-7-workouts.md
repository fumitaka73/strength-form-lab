# Issue #7 — 撮影なしのトレーニング記録（v0.4.0）

## 範囲と操作

履歴タブに「動画なしでセットを記録」を追加。RDL、スクワット、ベンチプレス、その他の自由入力を記録できます。これはトレーニング日誌の種目であり、スクワット/ベンチの動画解析への対応ではありません。日付・重量kg・回数・セット数を入力し、同内容のセットを1〜100個まとめて追加。セットごとに編集・削除できます。重量0kgは保存可能、空欄はnull（未入力）、回数は1〜10000の整数が必要です。日付は1900〜9999年の実在日、自由種目名は1〜80文字です。初期日付は端末の現地日付を使います。

日付・種目フィルターと日別/種目別の表で最大重量、合計回数、セット数、総負荷量を確認します。表の各日付行が重量・回数の推移を表します。総負荷量は重量×回数の合計、未入力重量は除外数を表示。効果や筋力の向上を保証する指標ではありません。グラフやクラウド同期、バックアップ、複数端末対応は今回の対象外です。

## 動画との関連・二重計上

任意で保存済み練習動画を1セットへ関連付けます。重量と端末現地の日付を初期値として引き継ぎ、回数は空欄に戻して本人の確認入力を要求します。角度レップ候補/体幹往復候補はどちらも自動加算しません。既存動画を日誌に自動変換しません。集計対象は新しいセット記録だけです。

1動画につき1セットまでのunique indexで、日付/種目を変えても二重リンクを拒否します。重量・回数を修正したいときは既存の関連セットを編集。元動画を編集してもセット記録を自動更新せず、元動画を削除してもセット日誌は保持します。関連解除/セット削除でも元動画は変更しません。動画IDがない手入力セット同士が同じ実セットかどうかは判別できないため、意図した登録数を本人が確認してください。

## 保存の影響

strength-form-lab v2 → v3。既存sessions/summariesは変更・削除・再生成せず、workoutSets storeとsourceSessionId unique indexだけ追加。元動画、Pose、Good Form、解析版、重量、レビューを保持します。v1からの既存概要作成も引き続き利用可能。sports-form-lab v4は開きません。セットのまとめ保存は1トランザクションで、重複リンクや保存失敗は全件を取り消します。旧アプリのv2コードへの戻しはv3のDBを直接開けないため、ダウングレード時は対応するコードが必要です。DB削除での復帰は行わないでください。

バックエンド/APIキー/外部送信なし。Safariのサイトデータ消去・OSの容量整理で失われる可能性は残ります。元動画を保管してください。初回更新には他のアプリタブを閉じる必要がある場合があります。

## iPhone Safariの確認手順（実機未検証）

1. 旧動画/Good Form/重量/メモがある端末で、更新後に各記録を開き、動画・骨格・内容が残っていることを確認。
2. 動画を選ばず履歴タブへ。RDL 40kg×8回を2セット、スクワット0kg×10回、その他の名前付き種目を追加。
3. 同日・別日の記録を追加し、日付/種目で絞る。RDLの1セットを45kg×6回に変え、合計14回・総負荷量590kgになることを確認。
4. Safariを再読み込みし、編集が残ることを確認。1セット削除して再読み込みし、元動画は残ることを確認。
5. 重量空欄と0kgが区別されること、空欄/0/小数の回数や負の重量・不正な日付が保存されないことを確認。
6. 動画を関連付けて重量が引き継がれ、回数は自動入力されないことを確認。同動画を別セットに再関連付けすると拒否され、余分なセットが保存されないことを確認。
7. キーボード、日付ピッカー、44px以上のタッチ対象、下部3タブ・safe-area、大量記録/空き容量不足の表示を確認。

Chromiumのモバイル幅テストとfake-indexeddbによる旧DB保持テストはSafari実機の確認を代替しません。実機でのDB更新、保存容量不足、画面復帰、動画形式・解析性能は未確認です。

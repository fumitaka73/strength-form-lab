# アプリUIとバージョン表示

## v0.2.0
- ヘッダーにStrength Form Labとpackage.json由来のバージョンを常時表示。
- iPhoneで片手でも画面を切り替えやすい下部3タブ（分析・Good Form・履歴）。
- 上部ヘッダーをコンパクトにし、動画選択とレビューへすぐ進める。
- safe-area、44px以上のタッチ対象、16pxの入力文字、狭い画面の折り返しに対応。
- 撮影設定と計測の説明を折りたたみ可能にする。
- 体幹候補だけの場合は「8 往復候補」のように検出した区間数を先頭に表示し、角度によるレップ確定・フォーム評価が保留であることを直下に表示する。
- 新しく保存した履歴の概要に往復候補数も保持する。以前の概要に数がない場合は「レビューで確認」と表示し、0件とは断定しない。

## バージョン運用
公開する更新ごとにnpm versionを使用し、package.jsonとpackage-lock.jsonを同期する。画面はこの値を参照する。バグ修正はpatch、機能・UI追加はminorを基本とする。解析アルゴリズムの版（rdl-2d-v4等）とは別の値。解析・保存・Good Form比較の条件はこのUI更新で変えない。

## 将来のネイティブ化
画面の遷移を分析・参照・履歴の3タブに統一し、端末内の動画選択→解析→レップレビュー→保存という流れを維持する。解析・保存モジュールは表示層から独立させる。将来WebViewを利用する場合も、ネイティブUIに置き換える場合も、この流れと文言を引き継ぐ。
この更新はWeb UIの整理であり、ネイティブ版の実装や配布は含まない。将来、動画選択・カメラ・保存・音声は各プラットフォームのAPIとの接続を検討する。
